## Overview

Rowboat builds your knowledge graph from the work you already do by integrating with your existing tools and data sources. All synced data is processed locally and stored in an Obsidian-compatible vault as plain Markdown files.

## How Syncing Works

1. **Background Process:** Each integration runs as a background service that checks for updates every 5 minutes
2. **Local Storage:** Synced data is written to `~/.rowboat/` as markdown or JSON files
3. **Knowledge Graph:** The graph builder monitors these folders and processes new/changed files into knowledge notes
4. **Entity Extraction:** AI extracts entities (people, organizations, projects, topics) from synced content
5. **Note Creation:** Entities are compiled into Obsidian-compatible notes with backlinks

## Data Privacy

<Info>
  All integrations are designed with privacy in mind:
  - **Local processing:** Data is processed on your machine, not sent to Rowboat servers
  - **OAuth security:** Cloud integrations use industry-standard OAuth 2.0
  - **Apple integrations:** 100% local, read-only database access with no cloud API calls
  - **Transparent storage:** All synced data is stored as plain text files you can inspect
</Info>

## Troubleshooting

### Google Integrations

**"Missing required scopes"**
- Ensure you've enabled all required APIs in Google Cloud Console
- Re-authenticate with Rowboat

**"401 Unauthorized"**
- Your OAuth token may have expired
- Re-authenticate through the onboarding flow

### Apple Integrations (macOS)

**"Database not found"**
- Ensure Mail.app or Calendar.app is installed and configured
- Check that database files exist in `~/Library/`

**"Permission denied"**
- Grant "Full Disk Access" permission in System Settings → Privacy & Security
- Restart Rowboat after granting permission

**"Database is locked"**
- Mail.app or Calendar.app currently has the database open
- Rowboat will automatically retry on the next sync cycle

### General

**"No new data syncing"**
- Check sync status in the services log
- Verify the integration is still enabled
- Check that source applications have new data to sync
